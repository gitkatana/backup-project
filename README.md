# 📦 Backup Project

Простой Bash-скрипт для автоматического создания архивных копий в Linux.  
Создан в учебных целях для отработки навыков автоматизации, работы с файловой системой и Git-воркфлоу.

## ✨ Что умеет скрипт
- Архивирует указанную папку с помощью tar + gzip
- Добавляет дату в имя файла для версионирования
- Автоматически создаёт целевую директорию, если её нет
- Выводит размер готового архива и статус выполнения
- Безопасно игнорирует архивы и логи через .gitignore

## 🛠️ Требования
- Linux (тестировалось на Ubuntu 24.04)
- Стандартные утилиты: bash, tar, gzip, date, du
- Базовые права пользователя для чтения исходной папки и записи в папку бэкапов

## 📂 Структура проекта
backup-project/
├── README.md
├── .gitignore
└── scripts/
    └── backup.sh

## ⚙️ Настройка
Откройте scripts/backup.sh и при необходимости измените переменные в начале файла:

Переменная SOURCE_DIR - Папка для архивации (по умолчанию: /home/katana)
Переменная BACKUP_DIR - Куда сохранять архивы (по умолчанию: /home/katana/backups)

## 🚀 Запуск
1. Сделайте скрипт исполняемым:
   chmod +x scripts/backup.sh

2. Запустите:
   ./scripts/backup.sh

## 📝 Пример вывода
Начинаю бэкап папки /home/katana...
✅ Бэкап успешно создан: /home/katana/backups/backup_2026-05-05.tar.gz
Размер файла: 149M
Готово!

## 🔒 Безопасность
- Файл .gitignore исключает *.tar.gz, *.log и папку backups/ из репозитория
- В код не вшиты пароли или персональные данные
- Перед запуском на боевых серверах рекомендуется тестировать в изолированной среде
